Design
FACEMESH_TESSELATION 기반 와이어프레임 메쉬 UI 전면 교체
기존 랜드마크 점 방식 → 468개 삼각형 연결선 기반 와이어프레임으로 교체. 화이트/사이언 색상, 검은 배경 위에 얇은 선으로 SF 의료 스캐너 느낌 구현. done 단계에서만 완성 메쉬 노출.
// Done mesh: white, higher opacity than grid ctx.strokeStyle = 'rgba(220,235,255,' + (0.18 + fb*0.08) + ')'; ctx.lineWidth = 0.5; // tesselation | 0.6 features | 0.6 oval
Feature
Surface-following Scan Glow 애니메이션
단순 레이저 라인이 아닌, 얼굴 depth(z좌표)를 반영한 표면 추적 스캔 구현. scanFrac(y,z)로 깊이 보정. GWIN=0.10 슬라이딩 윈도우, 이차함수 alpha falloff. scan_start 진입 즉시 시작.
function scanFrac(y, z) { return y + (z||0) * 0.20; } var effSP = phase === 'scan_start' ? 0.05 : window.scanProgress; var alpha = norm * norm * 0.32; // quadratic falloff
Fix
좌우 반전 이중 미러 버그 수정
vx()에서 x 미러 + 캔버스 ctx.scale(-1,1) 이중 반전으로 메쉬가 얼굴 반대 방향으로 움직이던 버그. vx에서 미러 제거, 캔버스 플립만 유지. sp 좌표도 1-vx()로 보정.
// BEFORE (double mirror bug) function vx(x) { return 1 - (x*sx + ox); } // AFTER (single mirror via canvas flip only) function vx(x) { return x*sx + ox; } // sp screen coords: x = 1 - vx(lm.x)
UX
AlignFrame 타원 가이드 + 2초 카운트다운
idle + aligning 두 단계 모두에서 타원 가이드 표시. aligning 진입 시 2초 카운트다운. SVG fillRule=evenodd로 타원 외부 마스킹, 모서리 L자 브래킷 4개.
{(scanPhase === 'idle' || scanPhase === 'aligning') && <AlignFrame/>} {scanPhase === 'aligning' && <Text>{alignSeconds}</Text>}
UX
프레임 이탈 UX — 1s 경고 / 2s 자동 중단
스캔 중 얼굴이 프레임 밖으로 나가면: 1초 미만 무시 → 1초 경과 시 주황 경고 텍스트 → 2초 경과 시 자동 리셋(idle 복귀). 얼굴 복귀 시 타이머 즉시 취소.
faceOutTimerRef → 1000ms → setScanWarning(true) faceOutWarnTimerRef → +1000ms → setPhase('idle') + reset
Design
Full-Screen CAD Grid Overlay
38px 정사각형 셀 기반 화면 전체 격자. 수직 ~10줄 + 수평 ~22줄 화면 끝까지 균등 분할. 타원 중심(OX=SW/2, OY=SH×0.40 ≒ 코 위치) 기준 십자선 별도 강조. 항상 표시, 모든 phase에서 유지.
const GRID_CELL = 38; const vxs = Array.from({length: Math.floor((SW-1)/GRID_CELL)}, (_, i) => (i+1) * GRID_CELL); // [38, 76, 114, ...] // Center crosshair at (OX, OY) — opacity 0.55 (vs grid 0.30)
Feature
17개 키 랜드마크 점 + 측정 항목별 색상
전체 468개 → 중심선 7개·눈 6개·입꼬리 2개·광대 2개, 총 17개로 최소화. 각 포인트가 해당 측정 항목(eye/mouth/face/center) 점수 색상으로 개별 렌더링.
var KM = [ [10,'center'], [9,'center'], [4,'center'], [152,'center'], [468,'eye'], [473,'eye'], [33,'eye'], [133,'eye'], [61,'mouth'], [291,'mouth'], [234,'face'], [454,'face'], ... ];
Feature
점수 ↔ 포인트 색상 실시간 동기화
done 단계에서 landmarks 메시지가 올 때마다 window.scoreEye/scoreMouth/scoreFace/scoreCenter를 WebView에 inject. FLabel(숫자) · Gauge(원형) · WebView 점 세 곳이 동일 smoothed 값으로 실시간 연동.
// landmarks 수신 시 done phase라면 즉시 inject if (phaseRef.current === 'done') { webRef.current?.injectJavaScript( `window.scoreEye=${s.eye};window.scoreMouth=${s.mouth}; window.scoreFace=${s.face};window.scoreCenter=${s.center};true;` ); }
Design
스캔 완료 후 화이트 메쉬 + 화면 디밍
done 단계 진입 시 메쉬 색상을 사이언 → 흰색 계열로 전환, 불투명도 상향. 카메라 피드에 rgba(0,0,5,0.22) 어두운 오버레이로 얼굴 부담 감소. 스캔 중 rgba(0,0,8,0.32)보다 밝게 유지.

Problem → Solution
문제 발견 & 해결 과정

실기기 테스트에서 발견된 3가지 주요 문제와 각 해결 방법.

Bug #1 이중 미러 — 메쉬가 얼굴 반대 방향으로 움직임
vx(x) = 1-(x*sx+ox) 로 x 미러 + ctx.scale(-1,1) 캔버스 플립 = 이중 반전. 얼굴이 오른쪽으로 움직이면 메쉬는 왼쪽으로 움직이는 현상. vx에서 미러 제거, 캔버스 플립만 유지로 해결.
BEFORE — 메쉬 좌우 반전, 점수 2-4%
→
AFTER — 얼굴에 정확히 매핑, 96-99%
Bug #2 스캔 전부터 완성 메쉬 노출 — 긴장감 없음
scan_start 단계부터 전체 테셀레이션 메쉬 + 아이리스 다이아몬드가 그대로 표시됨. 스캔의 의미가 없어지는 UX 문제. showMesh = isDone 조건으로 done 단계에만 완성 메쉬 표시, 스캔 중에는 subtle glow만.
BEFORE — scan_start부터 전체 메쉬 표시
→
AFTER — 스캔 중 카메라만, done에 메쉬 공개
Bug #3 468개 점 전체 출력 — 얼굴이 점으로 덮임
done 단계에서 468개 랜드마크 전체를 점으로 찍어 얼굴이 점 구름으로 가득 차는 문제. 눈·코·입꼬리·중심선·광대 총 17개 키 포인트로 최소화, 항목별 점수 색상 개별 적용.
BEFORE — 468개 점으로 얼굴 전체 덮임
→
AFTER — 17개 키 포인트, 항목별 색상
